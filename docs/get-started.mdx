Peyara has two parts: a lightweight **desktop server** (Rust) and the **mobile app**. Both devices need to be on the same Wi-Fi network.

- **Server:** [ayonshafiul/peyara-rust-server](https://github.com/ayonshafiul/peyara-rust-server/releases/latest) — Windows, macOS, Linux
- **App:** [ayonshafiul/peyara-mouse](https://github.com/ayonshafiul/peyara-mouse) — [Google Play](https://play.google.com/store/apps/details?id=io.github.ayonshafiul.peyara) · [App Store](https://apps.apple.com/us/app/peyara-remote-mouse/id6743374036)

## 1. Install and run the server

Install the server for your OS ([Windows](/docs/Installation/windows) · [macOS](/docs/Installation/mac) · [Linux](/docs/Installation/linux)) and launch it.

The server window shows a **QR code** with its network address. Keep it open. On Linux with a Wayland session (e.g. Ubuntu 24), approve the one-time "remote interaction" system prompt so the phone can control the desktop.

## 2. Install the mobile app

Install the Peyara app on your phone from Google Play, the App Store, or the [GitHub releases](https://github.com/ayonshafiul/peyara-mouse). Connect your phone to the **same Wi-Fi network** as your computer.

## 3. Pair with the QR code

Open the app, tap the **Plus (+)** button to add a server, and scan the QR code shown on the desktop window. The app verifies the code and saves the server — you only do this once.

## 4. Connect and control

Tap the saved server in the app list and press **Connect**. You can now:

- Move the cursor, click, right-click, drag, and scroll from the touchpad
- Type with your phone keyboard, including special and media keys
- Use play, pause, volume, and track controls
- Send text to the PC clipboard or pull text back to the phone

To switch computers later, add another server the same way and tap to switch.

If anything fails, see [Troubleshooting](/docs/troubleshooting).
